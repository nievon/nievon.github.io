# Портфолио — Никита (nievon)

Личный сайт-портфолио fullstack-разработчика с фокусом на backend: кейсы, услуги,
порядок работы, стек и контакты. Русская и английская версии, светлая и тёмная темы.

Сайт: https://nievon.github.io

## Стек

- Vite + TypeScript, без фреймворка
- Tailwind CSS v4
- Иконки Lucide, шрифты IBM Plex Sans и IBM Plex Mono (лежат локально)
- Деплой на GitHub Pages через GitHub Actions

## Запуск

```bash
npm install
npm run dev      # локальный сервер с горячей перезагрузкой
npm run build    # проверка типов и сборка в dist/
npm run preview  # просмотр собранной версии
```

Нужен Node.js 22 или новее.

## Где что лежит

| Что поменять | Файл |
| --- | --- |
| Кейсы: тексты, ссылки, стек, порядок | `src/data/projects.ts` |
| Услуги | `src/data/services.ts` |
| Матрица стека | `src/data/stack.ts` |
| Контакты | `src/data/contacts.ts` |
| Все остальные тексты интерфейса, RU и EN | `src/i18n.ts` |
| Скриншоты проектов | `src/assets/projects/` |
| Цвета, отступы, анимации | `src/style.css` |
| Разметка блоков | `src/sections/` |

### Добавить кейс

1. Добавьте запись в `src/data/projects.ts`. Все тексты задаются сразу на двух языках.
2. Чтобы у кейса был скриншот, укажите поле `photo` и положите файл в
   `src/assets/projects/<id>.webp`. Файл `<id>-dark.webp` будет показан в тёмной теме.
3. `visible: false` скрывает кейс с сайта, не удаляя его из кода.

### Картинка для превью ссылки

`public/og.png`, 1200 × 630. Адрес картинки прописан в `index.html` абсолютным,
потому что так требуют мессенджеры и соцсети. При смене домена поправьте его там же.

## Деплой

Пуш в ветку `main` запускает `.github/workflows/deploy.yml`: сборка и публикация
на GitHub Pages. В настройках репозитория должно быть выбрано
Settings → Pages → Source: GitHub Actions.

## Особенности

- На телефоне навигация вынесена в нижнюю панель, кейсы и карточки листаются свайпом.
- Анимации отключаются при системной настройке «уменьшить движение».
- Кнопка «Сохранить как PDF» печатает страницу как компактное резюме.
