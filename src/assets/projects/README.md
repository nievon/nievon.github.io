# Project photos

Drop one image per project here, named after the project id:

- `swageda.jpg`
- `natura.jpg`
- `chatvix.jpg`

`.jpg`, `.jpeg`, `.png`, `.webp` and `.avif` all work. The site picks the file up by name;
until a file exists the case shows an empty photo slot.

A landscape image around 1600 × 1200 px works best: it is cropped to fill the slot.
