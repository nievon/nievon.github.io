# Project screenshots

One image per project, named after the project id. A second file with the
`-dark` suffix is shown when the site is in its dark theme:

- `swageda.webp`, `swageda-dark.webp`
- `chatvix.webp`, `chatvix-dark.webp`
- `natura.webp` (and `natura-dark.webp` if the site has a dark theme)

`.jpg`, `.jpeg`, `.png`, `.webp` and `.avif` all work. The site picks files up by
name; until a file exists the case shows an empty slot.

Screenshots are shown as a window anchored to the top-left corner of the slot and
cropped on the right and bottom, so capture the top of the page. The current ones
are 1280 × 1000 CSS pixels at 1.5× scale.
